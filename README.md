# 清洁一平方米 · Clean a Little

根据德国卡赫创意 brief 制作的 3D 清洁互动原型。在一座微缩庭院里，洗净单车、长椅和地砖，让日常空间重新焕发色彩。

本仓库先交付可本地运行的浏览器游戏，不包含账号、支付或在线服务。

## 计划中的第一版

- 一个可旋转查看的 3D 庭院，包含三个清洁目标。
- 按住鼠标或触屏拖动清洗；切换清洗范围，观察真实的局部污渍消退。
- 分目标进度、音效、水流反馈和完成展示。
- 本地保存进度、继续体验和重新开始。

实现进度和运行方式随各里程碑更新，详见开发文档。
