## 已发现并修复的问题

1. 旋转后复位仍发生相机漂移：OrbitControls 保留了阻尼角速度，现于复位与聚焦前消耗剩余惯性。
2. Windows PowerShell 的 npm.ps1 吞掉附加命令选项：开发文档提供 npm.cmd 和直接 CLI 的执行方式。
3. 损坏存档验收最初在旧页面关闭前写入数据，被正常的 pagehide 自动保存覆盖：改为在新页面脚本启动前注入损坏数据，保留正确的自动保存行为。
4. Three.js r186 将旧的 PCFSoftShadowMap 自动降级为 PCFShadowMap 并输出弃用警告：改为直接使用 PCFShadowMap，保持相同阴影效果；生产检查同时拦截控制台警告。

## 范围与限制

- 单关网页原型，没有后端、多人、全局地图和正式三维产品模型。四款设备以厂商照片展示，当前庭院使用 KHB AIR。
- 只有一套清洗操作，两种喷幅属于游戏设置，未模拟真实流体、蒸汽、吸水或真实设备性能。
- 浏览器模拟验证了触摸输入和布局，未在 iOS / Android 真机上测试双指手势、GPU 性能、温度或耗电。
- 音频为程序合成；自动化验证音效开关状态与运行无错误，未进行听感评审。
- 当前 Three.js 分块约 567 kB（gzip 约 141 kB），构建会提示超过默认 500 kB 分块阈值。依赖已单独分块，不使用 CDN；这是产物体积提示，不是构建失败。
- 暂不把演示完成率当作目标玩家验证；后续仍需观察真实用户的理解、完成欲和下一关意愿。
