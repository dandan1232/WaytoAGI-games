# ADR 0001：先交付单关浏览器原型

日期：2026-10-24。状态：采用。

## 背景

用户基于德国卡赫创意 brief 希望制作 3D 清洁游戏，已授权在此仓库编写代码、留存需求与架构文档，并按独立验收点提交和推送。

平台未另作指定。已有讨论倾向于可快速试玩、便于演示和录屏的互动作品。项目初始只有空 README，没有既有框架或资产。

## 决策

采用 Three.js / TypeScript / Vite 构建浏览器游戏。首版提供一个程序化微缩庭院、同一把示意清洗枪、三个清洁任务。通过局部污渍网格与射线交互实现清洗，保留纯逻辑单元测试。

先在本地开发和验收，不注册托管站点、不自动发布、不添加账号和后端。每个可独立验收的里程碑 commit / push 到当前仓库远端。

## 取舍

收益：无需下载安装客户端、容易分享和录制、无外部模型版权和下载依赖、核心玩法能较快验证。

代价：程序化模型不等同于真实产品模型；没有真实流体、刷毛和蒸汽模拟；移动端性能须单独实测。

## 扩展条件

先观察目标玩家能否自然完成首关，并愿意继续下一关。通过后再增加不同设备、材质机制、关卡配置和全球清洁主题。只有出现联机、账号或排行榜需求时才引入服务端。
