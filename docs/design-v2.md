# 清洁小世界：四场景与界面改版

日期：2026-10-25。用户要求机器可拖动、补齐三个场景，并以 [Choo-Choo World](https://choochooworld.com/?DATA=DFFBHFIJB/0/D) 为参考重做页面和设置。

使用 frontend-design 与 UI/UX Pro Max。已实看参考站的开始页、3D 世界、工具和操作指引；借鉴场景占主画面、圆润控件、边缘工具与按需打开的面板，不复制其品牌、图形、音频或代码。初次设计搜索给出的 Swiss 营销页方向不适用，改用明确的 clay / toy 查询，匹配 Claymorphism，仅采纳圆润、实体按压反馈和清楚的可访问性约束。

## 设计方案

- 颜色：晴空蓝 `#d3eafb`、清洁黄 `#ffd524`、薄荷绿 `#75d8c6`、杏桃橙 `#ffac84`、织物紫 `#c3b0f3`、墨蓝 `#243c54`。四种场景色对应四个实际场景。
- 字体：标题用本地圆体优先的粗字重（Arial Rounded MT Bold / 幼圆 / Microsoft YaHei），正文用 Segoe UI / Microsoft YaHei；英文产品名使用粗体 sans-serif。无需远程字体。
- 布局：整个窗口就是可玩的世界；左上品牌和当前任务，右上设置；底部是四台机器对应的四场景选择器，侧边为清洁模式、视角工具；进度采用紧凑任务条。
- 标志性交互：厂商机器变成可抓起拖动的清洁工具，准星随拖动指针移动；各场景有不同笔刷与反馈，保留直接按住场景清洁和键盘操作。

```text
品牌 / 当前场景                           设置 / 指引
     小任务与总进度

                 3D 微缩世界
清洁模式 / 视角                     可拖动机器

          庭院  ·  窗边  ·  厨房  ·  客厅
```

对初稿的审视：保留旧的左右大卡片再换颜色仍会挤压玩法，因此删除营销式标题区和固定侧栏；场景选择直接可达，无需先进入装备图册。设置集中为昼夜、音效与音量、环境动画、操作指引和本关重置，避免用大量无功能的装饰按钮。桌面设置靠左展开，背景保持可见，切换昼夜可以立即观察环境变化；手机居中滚动。

每关独立存档、暂停、重玩和结算，旧庭院存档继续读取。设置与当前场景单独保存。产品照片仅用于识别和拖动，不宣称是真实产品三维数字模型或真实性能模拟。

验收须覆盖：四关真实输入清洗与完成、切换和刷新保留各关轨迹、鼠标 / 触屏拖动与边界约束、失焦 / 暂停停止、设置持久化、桌面与手机布局、减少动画，以及线上生产版本。
