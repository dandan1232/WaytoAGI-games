# 厂商设备素材接入

日期：2026-10-25。用户提供本仓库 `images/` 中的厂商产品素材，要求将机器加入游戏。

## 素材来源与处理

本地素材共 26 张，约 211 MB，包含四款设备的 PNG、JPG 与 TIFF 产品照片。未提供可编辑的三维模型。使用厂商原图的网页副本展示产品，不生成、重绘或镜像品牌标识。

| 设备 | 使用的原图（相对 images/） | 网页文件（相对 public/products/） |
| --- | --- | --- |
| KHB AIR 展开状态 | `KHB-AIR/KHB 1 (1).png` | `khb-air.webp` |
| KHB AIR 折叠状态 | `KHB-AIR/KHB 1 (3).png` | `khb-air-folded.webp` |
| WV 2 | `WV2/擦窗机专业摄影_正背面视角2.jpg` | `wv2.webp` |
| SC4D | `SC4D/1513280_std_01_96 dpi (jpg).jpg` | `sc4d.webp` |
| PUZZI 8-1 | `PUZZI-8-1/1100240_hero_01.tif` | `puzzi-8-1.webp` |

`scripts/prepare-product-assets.py` 用 Pillow 去除空白外边距、等比例缩小至最多 768×640，再转换为 WebP。KHB AIR 与 PUZZI 的原始透明通道得到保留；其他照片保留原有摄影背景。原图内容、比例及品牌标识不变，运行时不请求飞书或其他第三方资源。

复现：安装 Python 3 与 Pillow 后运行 `python scripts/prepare-product-assets.py`。普通开发和 Vercel 构建直接使用已提交的网页素材，不需要 Python、原图目录或转换依赖。

`images/` 原图及原有来源清单仅保留本地，加入 Git / Vercel 忽略规则，避免重复上传 211 MB 素材；压缩后的五张 WebP 随仓库提交。

网页素材合计 140,180 字节（约 137 KiB）：KHB AIR 展开图 27,240 字节，折叠图 31,836 字节，WV 2 为 12,210 字节，SC4D 为 16,462 字节，PUZZI 8-1 为 52,432 字节。首次进入只加载 KHB AIR，打开装备库后才请求其余产品；折叠图按选择加载。

## 接入范围与验收标准

- 当前庭院使用 KHB AIR：引导页、底部当前设备入口、清洗画面均能看到厂商设备；喷水起点对应机头。
- “卡赫装备库”可查看四款产品与 KHB AIR 的展开 / 折叠图，各产品说明对应清洗、镜面清洁、蒸汽清洁、布艺喷抽用途。
- 装备库打开时停止清洗和计时，关闭后恢复；不改动已有清洁进度和存档。
- WV 2、SC4D、PUZZI 8-1 在本关作为设备展示，界面明确其适用任务；独立玻璃、蒸汽和布艺玩法留待对应关卡。
- 手机与桌面均可打开、切换、返回；设备图不拦截庭院鼠标 / 触摸输入。
- 图像加载失败时保留设备名称和可操作的返回按钮，清洗不依赖图片加载成功。
- 设备展示使用照片，不将其表述为可旋转的产品三维模型；喷幅、清洁速度是游戏设定。
