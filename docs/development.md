## 开发命令

```powershell
npm ci
npm run dev
npm test
npm run check
npm run build
npm run preview
```

开发服务器默认只监听 127.0.0.1；需要局域网手机联调时，可明确运行 `npm.cmd run dev -- --host 0.0.0.0`，并按本机防火墙设置访问。Windows PowerShell 中 npm.ps1 可能吞掉额外选项，带参数时使用 npm.cmd，或直接运行 Vite CLI。

M2 使用 Three.js 0.186.1、TypeScript 7.0.2、Vite 8.3.5，完整解析版本由 `package-lock.json` 固定。

## 浏览器验收

```powershell
npm run test:e2e
npm run test:production
# 仅运行部分测试：
node node_modules/@playwright/test/cli.js test --grep "mobile layout"
```

配置使用本机 Chrome，缺少时可运行 `npx playwright install chrome`。测试在独立浏览器上下文中运行，不读取用户个人浏览器资料。使用 SwiftShader 以便无 GPU 环境验收，不据此保证真机帧率。完整通关测试可能需要约四分钟。

`test:production` 先构建，再使用系统分配的可用端口启动独立生产预览。检查真实清洗、页面错误、外部资源请求和开发测试入口，结束后自动关闭所启动的预览和浏览器。

验收脚本可复用已有的 5173 开发服务器，未运行时自动启动并结束服务器。日常开发启动的服务器仍由开发者自行关闭。

## 约定

- Node.js 22.14+，npm；提交 `package-lock.json` 后使用 `npm ci` 复现。
- 运行时资源留在仓库或打包产物内，不依赖 CDN。
- `.gitignore` 排除依赖、构建输出、运行日志、浏览器测试报告和临时工作文件。
- 文档使用中文，代码标识使用英文。
- 游戏参数与真实清洁设备参数分开，不发布无依据的产品性能数字。
- 第一版已完成本地项目；2026-10-24 用户追加 Vercel 部署要求，按 [部署说明](deployment.md) 将其扩展为静态网站托管。
