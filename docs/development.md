# 开发与验收记录

## 里程碑与提交

用户要求按可独立验收的点 commit / push。当前分支为 `main`，远端为 `origin`；只提交本任务文件，不推送密钥或临时截图。

| 里程碑 | 独立验收标准 | 状态 |
| --- | --- | --- |
| M1 需求与架构 | 明确创意来源、首版范围、交互、模块、清洁算法和后续验证 | 已完成文档 |
| M2 工程与逻辑 | 可安装启动；核心清洁与存档测试通过；类型检查和构建通过 | 已通过：17 项逻辑测试、类型检查与生产构建 |
| M3 可玩原型 | 真实 3D 庭院、清洗、三任务、保存、设置、完成展示；浏览器验收留档 | 待实现 |

每个里程碑验证后单独提交并推送。具体运行命令、依赖版本与实际验收结果随实现更新。

## 开发命令

```powershell
npm ci
npm run dev
npm test
npm run check
npm run build
npm run preview
```

开发服务器默认只监听 127.0.0.1；需要局域网手机联调时，可明确运行 `npm run dev -- --host 0.0.0.0`，并按本机防火墙设置访问。

M2 使用 Three.js 0.186.1、TypeScript 7.0.2、Vite 8.3.5，完整解析版本由 `package-lock.json` 固定。

## 约定

- Node.js 22.14+，npm；提交 `package-lock.json` 后使用 `npm ci` 复现。
- 运行时资源留在仓库或打包产物内，不依赖 CDN。
- `.gitignore` 排除依赖、构建输出、运行日志、浏览器测试报告和临时工作文件。
- 文档使用中文，代码标识使用英文。
- 游戏参数与真实清洁设备参数分开，不发布无依据的产品性能数字。
- 第一版先完成本地项目，不在本阶段注册 / 发布在线站点。

## 当前已知限制

- 尚未验证目标玩家的留存或付费意愿。
- 游戏是否符合活动投稿格式仍需确认。
- 真实产品工业设计模型、完整视频制作和其他清洁设备操作不在首版范围。
