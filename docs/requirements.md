# 需求文档

状态：首版范围已确定，功能按里程碑验收。日期：2026-10-24。

2026-10-25 已扩展为四场景与可拖动机器，当前追加范围见第 9 节；第 3 节保留首版范围记录。

## 1. 背景与来源

来源：[德国卡赫创意 brief](https://ocn8hd90aveq.feishu.cn/wiki/RRdmwGT1kiBXvRkfRa5c0ydCnAb)，2026-10-24 通过用户已打开的浏览器读取。

文档列出 AI 微短剧、AI 视觉奇观、解压爽片 / 测评 / ASMR 三条视频赛道，以及全球公益清洗专属主题。与本项目最相关的是“100 种污渍挑战”和“清洁一平方米，点亮一座城”。文档提供 WV 2、SC4D、KHB AIR、PUZZI 8-1 产品资料和参考视频。

这些是创意来源，不能据此认定已有游戏投稿通道。活动交付规则和真实产品参数尚未确认。本版使用程序化场景，2026-10-25 根据用户要求接入其提供的厂商设备照片；不将游戏数值表述为产品性能，不在本阶段制作完整产品数字模型。

## 2. 产品目标

让第一次进入的玩家在十秒内理解“按住冲洗”，在两至五分钟内完成一座微缩庭院的清洁，感受污垢消退、原色显现和环境恢复的满足感。

核心循环：观察目标 → 按住清洗 → 看见局部变化 → 完成一个区域 → 完成庭院 → 对比与重玩。

## 4. 交互约定

- 鼠标左键按住：清洗。右键拖动：旋转。滚轮：缩放。
- 触屏单指：清洗。双指：旋转 / 缩放。
- 1 / 2：切换喷幅；R：复位视角；M：开关音效；Esc：暂停 / 返回。
- 暂停、隐藏页面、取消触摸或失去焦点后立即停止喷射和音效。
- 指引、暂停、结算面板打开时停止清洗。
- 单个任务到达完成阈值后保留完成状态，不要求寻找难以看见的最后几个像素。
- 重新开始先打开确认对话框；取消保留原进度。

## 5. 视觉与内容

暖白、炭黑、清洁黄与植物绿。采用有柔和阴影的微缩庭院、可辨识的几何单车和木质长椅。中文界面，系统字体，无运行时远程字体和外链素材依赖。

优先保证污渍和清洁区域的反差、可操作区域大小、任务进度可读性。页面展示的是游戏体验，不展示调试指标或实现细节。

## 6. 质量标准

- `npm run check` 通过类型检查；`npm test` 通过核心逻辑测试；`npm run build` 成功。
- 浏览器自动化验证加载、交互、进度持久化、视角、设置、重新开始及完成流程；记录实际覆盖和限制。
- 桌面 1440×900 与移动端 390×844 布局无横向溢出，主要按钮可见。
- 渲染循环使用帧间隔，切后台不累计喷射；限制像素比和粒子量。
- 存档有版本和校验；损坏数据不导致白屏；保存失败不阻断游戏。
- 不对未经测量的设备帧率作保证，不将完成原型等同于验证商业需求。

## 7. 后续验证

邀请目标用户试玩，观察是否能独立开始、是否主动完成、在哪一步重复或疲劳，以及是否愿意再玩一关。先验证手感和完成欲，再扩展关卡、产品和品牌视频。

## 8. 厂商设备接入（2026-10-25）

用户提供 `images/` 的四款厂商机器照片，要求加入现有游戏。当前庭院清洗对应 KHB AIR，使用原厂透明产品图呈现当前设备，水流起点对应机头，替换原来的黄色示意机器。引导和底部工具栏显示型号，工具栏可打开“卡赫装备库”。

装备库包含 KHB AIR、WV 2、SC4D、PUZZI 8-1 的产品图、适用任务和说明；KHB AIR 可切换展开 / 折叠图。当前使用的设备与设备展示有明确标记，其余三款不使用本关水流冒充蒸汽、吸水或喷抽操作。

打开装备库时停止清洗、音效和游戏计时；关闭、返回或 Esc 后恢复庭院，原有进度与存档继续有效。设备图不阻挡画面上的清洗输入。图片不可用时仍可查看产品名称、返回并继续游戏。

素材处理、原图映射、体积与具体验收标准见 [厂商设备素材接入](product-assets.md)。

## 9. 可拖动机器、三个新增场景与 UI 改版

用户追加要求：机器可拖动；补齐 WV 2、SC4D、PUZZI 8-1 的三个可玩场景；使用 UI skill，并参考 Choo-Choo World 重做网页和设置。

| 场景 | 设备与操作 | 独立任务 |
| --- | --- | --- |
| 庭院日常 | KHB AIR 水流冲洗 | 单车、长椅、地砖 |
| 晴天窗边 | WV 2 扁平擦拭，玻璃由污浊变清透 | 左、中、右玻璃 |
| 元气厨房 | SC4D 蒸汽与油污移除 | 灶台、瓷砖背墙、厨房地砖 |
| 柔软客厅 | PUZZI 8-1 喷抽与织物显色 | 沙发、靠垫、地毯 |

- 鼠标 / 单指可抓住机器拖动，清洁准星随指针经过污渍而清洁；保留直接按住场景清洁。
- 机器可使用方向键移动，按住空格清洁；“收回机器”恢复停靠位置；窗口变化后机器仍可触达。
- 四场景随时切换，各自保存污渍和用时；刷新恢复当前场景及其状态，重玩仅重置当前关。
- 四关均能通过真实指针输入达到三个任务完成并结算；各任务仍采用 92% 余渍收尾。
- 界面围绕全屏场景安排，移除旧营销标题与固定右侧任务卡；四场景与设备在底部直接可达。
- 设置包含昼夜、音效、音量、环境动画、指引与本关重置。设置打开时停止操作与计时，保存偏好；夜间同时改变实际场景光照。
- 桌面设置靠左展开；手机与横屏支持滚动，主要返回按钮可达；尊重减少动画偏好。
- 设计来源、配色、字体、布局和验收约定保存在 [改版设计文档](design-v2.md)。
